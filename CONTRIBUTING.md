# Feedback for Poster Studio

Thank you for helping make Poster Studio better. Bug reports and feature
suggestions are welcome through GitHub Issues. Code contributions and pull
requests are not currently accepted.

## Useful issue reports

- Search existing issues before opening a new one.
- Include clear reproduction steps, expected behavior, and actual behavior.
- Mention the poster mode, template, format, DPI, and browser when relevant.
- Screenshots should not contain copyrighted artwork, credentials, or personal data.
