# Changelog

Notable changes to Poster Studio are documented here in German and English.

## Unreleased

### Deutsch

- Custom Poster können jetzt für mehrere Druckformate in einem Durchgang als PNG, PDF oder beides exportiert werden. Die Formate werden einzeln neu gerendert, verwenden die gewählte DPI-Einstellung und werden gemeinsam als ZIP-Datei heruntergeladen. Eine Fortschrittsanzeige und formatbezogene Auflösungswarnungen begleiten den Export.
- Die Beschreibung in den Custom-Poster-Templates Editorial White und Editorial Dark kann jetzt bis auf 300 % skaliert werden.
- Editorial-Beschreibungen nutzen die verfügbare Zeilenbreite genauer. Der automatische Umbruch berücksichtigt schmale und breite Zeichen, während manuelle Zeilenumbrüche und lange Wörter weiterhin sicher verarbeitet werden.

### English

- Custom Posters can now be exported for multiple print formats in one run as PNG, PDF, or both. Each format is rendered independently with the selected DPI setting and downloaded in a single ZIP archive, with progress feedback and format-specific resolution warnings.
- Description text in the Editorial White and Editorial Dark custom poster templates can now be scaled up to 300%.
- Editorial descriptions use the available line width more accurately. Automatic wrapping now accounts for narrow and wide characters while preserving manual line breaks and safely handling long words.
